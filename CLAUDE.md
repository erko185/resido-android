# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Git rules

- **Never commit or push without an explicit instruction from the user.** Implementing a change does not imply permission to commit it — wait until the user says to commit/push.
- **Commits go out under the user's own git identity only.** Do not add `Co-Authored-By: Claude ...`, "Generated with Claude Code", or any other AI attribution to commit messages or PR descriptions.
